# Corrugados y Cajas de Delicias

Sitio con React + Vite, administrado con pnpm.

## Local
```
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # genera /dist
```

## Datos del negocio
Teléfonos, WhatsApp, productos y sucursales se editan en `src/data.js`.
Las fotos están en `public/images`.

## Cloudflare Pages
- Framework preset: Vite (o None)
- Build command: `pnpm build`
- Build output directory: `dist`
- Variable de entorno (opcional): `NODE_VERSION = 20`
